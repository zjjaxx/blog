# 红利 ETF 布林带多周期量化策略：设计方案与实现计划

> 理论依据：约翰·布林格《布林线》（地震出版社）
> 结构：月线看趋势 → 周线定机会（只用机会 A 趋势回踩、机会 C W 底反转） → 日线找买点（站上中轨，成交量 + RSI 确认）
> 实现：Python 回测 + 每日选股
> 标的：红利类 ETF / 指数

---

## 1. 书中核心理念与落地方式

| 理念               | 落地方式                                             |
| ------------------ | ---------------------------------------------------- |
| 布林带衡量相对高低 | 用 %b、带宽（BandWidth）做标准化判断                 |
| 参数随周期调整     | 20 周期配 2.0 倍；10 周期配 1.9 倍；50 周期配 2.1 倍 |
| 触及轨道不是信号   | 买入必须叠加量能和动量确认，“沿带行走”时不止盈       |
| 用独立指标确认     | 成交量类（MFI、II%）为主，RSI 为辅                   |
| W 底 / M 顶        | 机会 C 的买入形态；M 顶用于减仓                      |
| 指标也可以套布林带 | RSI 套 BB(50, 2.1)，作为自适应的超买线               |

### 1.1 指标定义

```
中轨 MID   = MA(C, N)
上轨 UPPER = MID + K × STD(C, N)
下轨 LOWER = MID − K × STD(C, N)
%b         = (C − LOWER) / (UPPER − LOWER)
带宽 BW    = (UPPER − LOWER) / MID

RSI(14)    : Wilder 平滑
MFI(10)    : 典型价 TP = (H + L + C) / 3，资金流 = TP × VOL，
             MFI = 100 − 100 / (1 + 正资金流和 / 负资金流和)
II%(21)    : Σ[(2C − H − L) / (H − L) × VOL] / Σ VOL × 100
量比 VR    : VOL / MA(VOL, 20)
ATR(14)    : 真实波幅均值
RSI 布林带 : BB(RSI, 50, 2.1)
```

## 2. 三周期分层

| 层级           | 作用                             | 布林参数                                  | 输出             |
| -------------- | -------------------------------- | ----------------------------------------- | ---------------- |
| 月线           | 判断方向，决定能不能做、仓位多大 | BB(20, 2.0)，历史数据不够时用 BB(10, 1.9) | 多 / 中性 / 空   |
| 周线（主策略） | 判断有没有机会、是哪种机会       | BB(20, 2.0)                               | A / C / 无       |
| 日线           | 入场时机                         | BB(20, 2.0)                               | 买入信号、止损价 |

> ETF 上市不足 20 个月时，月线和周线趋势改用它跟踪的指数来算（例如中证红利指数 000922）；日线买点仍然用 ETF 本身的数据。

### 2.1 月线：趋势过滤

| 状态 | 条件                                                         | 处理                     |
| ---- | ------------------------------------------------------------ | ------------------------ |
| 多头 | 月收盘 > 月中轨，且月中轨 > 3 个月前的月中轨                 | 满额仓位                 |
| 中性 | 收盘在中轨之上但中轨走平或向下，或者收盘在中轨之下但中轨仍向上 | 半仓                     |
| 空头 | 月收盘 < 月中轨，且月中轨向下                                | 禁止开新仓，已有持仓清仓 |

- 加分项：月 RSI(14) > 50。
- 过热：月 %b > 1 且月 RSI > 80 时，仓位减半。

### 2.2 周线：主策略

#### 机会 A：趋势回踩（顺势）

同时满足以下条件：

1. 周收盘 > 周中轨，且周中轨 > 4 周前的周中轨（趋势向上）。
2. 最近 3 周内，某根周线的最低价 ≤ 周中轨 × 1.02（确实回踩过中轨附近）。
3. 周 %b 在 0.3 到 0.8 之间（没有过度延伸）。
4. 周 MFI(10) > 40（没有出现资金大幅流出）。

#### 机会 C：W 底反转（书中“方法 III”）

只在月线为多头或中性时启用。按顺序识别：

1. **第一个低点 L1**：周收盘跌破下轨（%b < 0）。宽松模式下改为“周最低价触及下轨”或 %b < 0.05。
2. **反弹**：L1 之后出现反弹，周 %b 回到 0.5 附近，或收盘接近中轨。
3. **第二个低点 L2**：价格低于或接近 L1（L2 ≤ L1 × 1.03），但周 %b > 0，也就是没有再跌破下轨。
4. **背离确认**：L2 处的 RSI 或 MFI 高于 L1 处的值。
5. **形态确认**：L2 之后周收盘站上周中轨。
6. **形态时限**：从 L1 到形态确认不超过 26 周，超时作废。

参数开关：`c_mode = strict | relaxed`。由于红利 ETF 波动小，严格模式下信号可能极少，所以宽松模式要单独回测对比。

#### 周线排除条件

周 %b > 1 且周 RSI > 75，或者周 RSI 超过它自己的 BB(50, 2.1) 上轨，视为过热，只观察不出信号。

#### 机会 A、C 同时成立时

取得分更高的那一个，标记为 `A+C`，并单独统计这类信号的表现。

### 2.3 日线：买入触发

| 类别       | 条件                                                      | 是否必需 |
| ---------- | --------------------------------------------------------- | -------- |
| 站上中轨   | 昨收 < 昨日中轨，今收 > 今日中轨                          | 必需     |
| 防假突破   | 收盘 ≥ 中轨 × 1.005，或连续 2 日收在中轨之上              | 必需     |
| 量能       | 量比 > 1.2 且当天收阳线，同时 MFI(10) > 50 且比前一日上升 | 必需     |
| RSI        | 本次触发前 3 日内 RSI 上穿 50，当前 RSI 在 50 到 70 之间  | 必需     |
| RSI 自适应 | RSI < 它自己的 BB(50, 2.1) 上轨                           | 必需     |
| 盈亏比     | (日上轨 − 收盘) / (收盘 − 止损价) ≥ 1.5                   | 必需     |
| II%        | II%(21) > 0                                               | 加分     |

> ETF 的成交量有时会被单笔大额申赎或折溢价套利放大，所以量能必须是“量比 + MFI”两个条件同时满足，不单看量比。

**时间窗口**：周线机会出现后的 4 周内，日线触发才有效。

## 3. 综合买入公式

```
硬条件 = 月线状态 ≠ 空头
       且 周线机会 ∈ {A, C}
       且 周线没有触发排除条件
       且 日线所有“必需”条件都满足

评分（满分 100）:
  月线 30 分：多头 30，中性 15；月 RSI > 50 加 5（最多封顶 30）
  周线 40 分：
      A：基础 30；周 MFI > 50 加 5；周中轨斜率处于历史前 30% 加 5
      C：基础 30；RSI 与 MFI 同时背离加 5；L2 处成交量 < L1 处成交量（抛压衰竭）加 5
  日线 30 分：量比 > 1.5 加 10；MFI 上升加 10；
             RSI 在 50–65 区间加 10（65–70 区间只加 5）；II% > 0 加 5（最多封顶 30）

买入 = 硬条件 且 评分 ≥ 70
```

## 4. 仓位与风控

### 4.1 仓位

- 每笔交易的风险为总资金的 1%：仓位 = 1% × 资金 / (入场价 − 止损价)。
- 再乘月线系数：多头 × 1.0，中性 × 0.5，月线过热 × 0.5。
- 单只 ETF 最多占总资金的 40%，所有持仓合计不超过 100%。

### 4.2 止损

| 机会     | 初始止损                                                     |
| -------- | ------------------------------------------------------------ |
| A        | 取“日下轨”和“近 10 日最低价”中较低的那个                     |
| C        | W 底第二个低点 L2 的最低价 × 0.99                            |
| 通用上限 | 单笔最大亏损不超过 8%；也可以改用“入场价 − 2 倍 ATR”（参数开关） |

### 4.3 卖出

1. **部分止盈（减仓一半）**：
   - 日线出现 M 顶：第二次冲高时 %b < 1，同时 RSI 或 MFI 背离。
   - 或者周 %b > 1 之后又收回带内。
2. **沿带行走**：价格沿着日上轨走时不止盈，改用日中轨做移动止损，日收盘跌破中轨就离场。
3. **趋势离场（清仓）**：周收盘跌破周中轨，且周中轨走平或向下。
4. **强制离场（清仓）**：月线转为空头。

## 5. 补充事项

1. **避免用到未来数据**：日线信号只能使用“已经走完的上一根”周线和月线（`mode = closed`）。如果要用当周还没走完的周线，单独设为 `mode = live` 并分开回测。
2. **复权**：ETF 也会分红，指标计算用等比前复权，收益计算用后复权或全收益口径。
3. **股息率过滤（可选）**：跟踪指数的股息率在近 5 年的分位 > 50% 才允许开仓。数据来自中证指数官网，实现时确认 akshare 对应接口。
4. **交易规则**：T+1；涨跌停 10%，涨停买不进、跌停卖不出；没有印花税，成本按单边 0.05% 到 0.1% 估算；滑点 0.05%。
5. **信号成交价**：以日线收盘确认信号，按下一个交易日的开盘价成交。

## 6. 回测设计

### 6.1 候选标的（实现时确认）

- 510880 华泰柏瑞红利 ETF
- 515080 中证红利 ETF
- 512890 红利低波 ETF
- 159905 深证红利 ETF
- 对应指数：000922 中证红利、H30269 红利低波等

### 6.2 对照组

| 组别   | 说明                           |
| ------ | ------------------------------ |
| G1     | 只用机会 A                     |
| G2     | 只用机会 C（严格模式）         |
| G3     | 只用机会 C（宽松模式）         |
| G4     | A + C（主方案）                |
| 基准 1 | 只看日线上穿中轨，没有任何过滤 |
| 基准 2 | 红利指数买入持有（全收益）     |
| 基准 3 | 每月定投                       |

### 6.3 评价指标

- 年化收益、最大回撤、卡玛比率、夏普比率
- 交易次数、胜率、平均盈亏比、平均持仓天数
- 资金利用率（持仓时间占比）
- 按机会类型（A / C / A+C）分别统计

### 6.4 稳健性检验

- 参数敏感性：周期 N 取 18 到 22，倍数 K 取 1.9 到 2.1，量比阈值取 1.1 到 1.5，评分阈值取 60 到 80。
- 样本内外：例如 2010–2019 年做样本内，2020 年至今做样本外。
- 滚动前进：3 年训练、1 年测试，逐年滚动。
- 结果判定：如果参数稍一变化、收益就大幅波动，说明过拟合，应该放弃这组参数。

## 7. 实现计划

### 7.1 项目结构

```
红利/
├── 布林带多周期策略方案.md
├── config.yaml              # 标的池、参数、开关
├── requirements.txt         # pandas, numpy, akshare, matplotlib/plotly, pyyaml
├── data/                    # 本地缓存（parquet）
├── src/
│   ├── data_loader.py       # 拉取、复权、缓存；日线合成周线和月线
│   ├── indicators.py        # BB / %b / BW / RSI / MFI / II% / ATR / VR / 指标布林带
│   ├── patterns.py          # W 底、M 顶、沿带行走识别
│   ├── signals.py           # 月线状态、周线机会、日线触发、评分
│   ├── risk.py              # 止损、仓位、卖出规则
│   ├── backtest.py          # 逐日推进的回测引擎（T+1、涨跌停、手续费）
│   ├── report.py            # 绩效指标、分组对比、图表
│   └── screener.py          # 每日选股输出
├── tests/                   # 指标与形态的单元测试
└── run_backtest.py / run_screener.py
```

### 7.2 分阶段

| 阶段      | 内容                                                         | 验收标准                                     |
| --------- | ------------------------------------------------------------ | -------------------------------------------- |
| P1 数据层 | akshare 拉取 ETF 和指数日线；等比复权；合成周线和月线；本地缓存 | 周线、月线的 OHLCV 与行情软件一致            |
| P2 指标层 | 实现第 1.1 节全部指标                                        | 和通达信或同花顺抽样对比，误差 < 0.1%        |
| P3 形态层 | W 底（严格 / 宽松）、M 顶、沿带行走                          | 人工核对历史上的典型样本，并出图             |
| P4 信号层 | 月线状态机、周线 A / C、日线触发、评分                       | 输出每个信号的明细（每一项条件的真假和得分） |
| P5 风控层 | 止损、仓位、减仓、清仓规则                                   | 单元测试覆盖所有离场分支                     |
| P6 回测层 | 引擎、成本、交易规则、对照组 G1–G4 和基准                    | 输出第 6.3 节全部指标                        |
| P7 稳健性 | 参数扫描、样本内外、滚动前进                                 | 生成参数热力图，确定最终参数                 |
| P8 输出层 | 每日选股清单 + 三周期图（K 线、布林带、RSI、MFI、成交量）    | 一条命令生成当日报告                         |

### 7.3 关键风险

- **信号稀少**：红利 ETF 波动小，机会 C 的样本可能不足。处理方式：合并多只 ETF 和指数一起统计，并对比宽松模式。
- **ETF 历史短**：用跟踪指数补足月线和周线的趋势判断。
- **数据源**：akshare 接口可能变动。处理方式：数据层做抽象，保留切换到 tushare 的能力。
