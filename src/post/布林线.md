## 核心理念

1. 用布林带给价格的高低下一个相对的定义。
2. 布林带只是参照系，交易决定要靠价格形态、基本面、动量RSI和成交量一起判断。
3. 不做纯技术派，也不做纯基本面派，而是把两者结合起来。
4. 用基本面挑出值得关注的股票，再用布林带和技术指标决定什么时候进、什么时候出。

## 投资偏好

主要以长期作为主要趋势作为偏好来投资，"一主两辅"的多周期观察方法，主周期为周线，产生实际的交易决定，月线看位置和估值，决定"该不该买、该积极还是谨慎"。日线优化执行时机，比如进场点和止损点。

## 指标参数

1. 价格口径（两套并用）
   - **技术面**（布林带、%b、周/月线位置、日线是否站上中轨）：使用**前复权**行情，避免除权缺口扭曲中轨与 %b。
   - **成交与估值**（买卖成交价、股息率分母、现金分红入账）：使用**不复权**真实成交价与派息。

2. 布林带的参数

| 用途 | 移动平均周期 | 标准差倍数 |
| :--- | :----------- | :--------- |
| 中期 | 20           | 2.0        |

3. %b：价格在带内的位置 %b=(价格−下轨)/(上轨−下轨)
   - %b = 1 在上轨，%b = 0.5 在中轨，%b = 0 在下轨；大于 1 或小于 0 表示在带外。
4. 带宽=(上轨−下轨)/中轨
5. RSI：周期 14，用于判断动量。
6. MFI（资金流量指数）：周期 10，用于判断成交量。
   - 典型价格 = (最高 + 最低 + 收盘) / 3
   - 资金流 = 典型价格 × 成交量
   - 典型价格高于前一周期记为正资金流，低于前一周期记为负资金流
   - MFI = 100 − 100 / (1 + 10 期正资金流之和 / 10 期负资金流之和)
   - MFI 是用成交量加权的 RSI。布林格在书中用 %b 配合 MFI 做判断，用它代替"看成交量多少"的主观判断。
7. 均量：最近 20 周成交量的简单平均，用于判断放量、缩量。
   - 放量：当周成交量 ≥ 1.5 × 均量
   - 恐慌性抛售：收跌且当周成交量 ≥ 2 × 均量
   - 缩量：当周成交量 ≤ 0.8 × 均量

## 基本面筛选（硬门槛，先于一切买卖判断）

以下 5 条必须**全部同时满足**，才允许进入后面的技术面买卖步骤；任一不满足 → **不看图、不买入、不加仓**。持仓期间若基本面失效（例如股息率掉到门槛以下、分位回落、分红中断、现金流不再覆盖分红、市值长期低于门槛），只允许按第五步减仓/清仓，**不得再开新仓或回补**。

1. **股息率 ≥ 2×30 年国债收益率**（绝对水平；用当前股息率 vs 当日或最近可得的 30 年国债收益率）。
2. **股息率处在自身历史较高分位**：上市以来股息率序列（至少约 5 年）中，当前值历史分位 ≥ 80%（相对自身更便宜；不能替代第 1 条绝对门槛）。
3. **连续 3 年分红**。
4. **现金流能覆盖分红**：近 3 年经营现金流净额合计 ≥ 近 3 年现金分红合计。
5. **市值 ≥ 800 亿**。

### 当前股息率怎么算

**股息率 = 完整一年每股股息 / 当前价**（价格用当日不复权收盘价；派息取「实施」且已除权的现金派息，口径为元/股）。

**完整一年每股股息**按自然年的派息「期」拼接，不用滚动 365 天：

1. 以上一日历年实际派息的**月份**为模板（一年一派就是 1 期，一年两派就是 2 期）。
2. 对每一期：
   - **今年同月已经派了** → 用今年该期实派；
   - **今年同月还没派** → 用**去年同期**实派代替。
3. 因此一年两派、今年才派完第 1 次时：总股息 = **今年已派的这一次 + 去年「类似今年还没派的那一次」**。
4. 今年多出了去年没有的新派息月 → 额外计入。
5. 上市初期尚无上一日历年可参照时：用已实施记录里最近一个完整日历年的派息合计。

举例：某股去年 1 月派 1.0、7 月派 2.0；今年 1 月已派 1.1、7 月未派 → 完整一年 = 1.1（今年 1 月）+ 2.0（去年 7 月）= 3.1；待今年 7 月派 1.9 后 = 1.1 + 1.9 = 3.0。

## 买卖步骤

顺序固定：**基本面硬门槛 → 月线 → 周线 → 日线买入 → 持有 → 分批离场**。未过基本面，后面步骤全部跳过。

### 第 0 步：基本面硬门槛

复核上一节 5 条（含绝对股息率与历史分位）。全部通过 → 才进入第一步；否则当日及之后在重新满足前，不做买入判断。

### 第一步：月线定位置

在第 0 步已通过的前提下：

**价格在月中轨及以下**：用**截至当日的当月 forming 月线**重算中轨（例：10 月 15 日就用含 10/15 收盘的当月 K 算月中轨），最新价（当日收盘）≤ 该中轨。周线、日线同理，一律用「截至当日」的 forming K，不用上一根已收完 K 延后许可。

### 第二步：周线找相对低位（主周期信号）

周收盘 %b ≤ 0.25（贴近下轨）。

**必须在买入日当天仍满足**，不采用「曾经跌到过 ≤0.25、之后周线已修复仍可买」的延后许可；第二步与第三步同一天同时成立才执行买入。

### 第三步：日线找进场时机

买入前再次确认第 0 步仍全部满足；任一失效则不买入。

在第二步当日已满足的前提下（日线布林用前复权）：

1. 当日最低价 > 日线中轨（站上中轨），且当前价在中轨附近 **0.5 < %b ≤ 0.8**，执行买入。
2. **同月限购**：同一只股票在同一个自然月内最多买入 **1 次**（多账号共用此限制，当月已买过则不再开新仓）。

### 第四步：买入后不卖出，跌了吃股息回本

前提是买入时已严格通过第 0 步；持有期靠股息消化浮亏，不因日线波动止损。

### 第五步：分批减仓与全部离场

1. **周线上轨减仓 20%**：周收盘 %b ≥ 1.0（触及或站上周线上轨），卖出当前持仓的 20%。同一次上涨行情中该档只执行一次。
2. **月线上轨减仓 30%**：月收盘 %b ≥ 1.0（触及或站上月线上轨），卖出当前持仓的 30%。同一次上涨行情中该档只执行一次。
3. **股息率分位 80→70 阶梯减仓**：买入要求分位 ≥ 80%；当持仓期间分位从高位回落、进入 80～70 区间时，**每下降 2 个百分点减仓一档**：
   - 触发档：历史分位 ≤ 78、≤ 76、≤ 74、≤ 72、≤ 70（各档只执行一次）；
   - 每档卖出「首次触发本阶梯时持仓股数」的 **10%**（固定股数，不是滚动按余仓再 10%）；
   - 五档合计最多减掉该基准的 50%；
   - **分位 ≤ 70% 时，在最后一档减仓后，剩余仓位全部清仓**（估值离场结束）。

## 回测怎么跑

买卖规则与上文第 0～5 步一致；下面只记回测执行逻辑本身的约定。

### 数据与口径

1. 日线行情两套：**不复权**用于成交价、股息率分母、现金分红入账；**前复权**用于布林带、%b、站上中轨、周/月线位置。
2. 周线 / 月线由前复权日线聚合；布林带统一 BB(20, 2)。
3. 股息序列取「实施」且已除权的现金派息；当前股息率按上文「完整一年拼接」口径。
4. 历史分位：该股上市以来股息率序列中，当前值的百分位（样本不足约 5 年的早期日期不参与买卖）。
5. 基本面硬门槛五条都进 `hard_ok`：股息率 ≥ 2×30Y、**历史分位 ≥ 80%**、连续 3 年分红、近 3 年经营现金流合计 ≥ 近 3 年现金分红合计、市值 ≥ 800 亿。现金流用年报还原（CFO≈CFOToNP×净利润；分红总额≈每股派息×总股本）；市值若未传入可按回测简化默认通过。

### 多账号滚动

一只股票对应若干**彼此独立、规则相同**的子账户。默认**按需建户**：有空闲账号则复用；全忙则新建一个 100 万账号接单（不再先固定 N 再记 miss_busy）。

1. **每个账号**：初始 100 万；全仓买入 / 按第五步比例卖出；除权日把每股派息 × 持股记入现金；独立持仓、独立减仓档位（周上轨 20% / 月上轨 30% / 股息阶梯）；独立记本金浮亏与回本。
2. **买入条件**（当日同时满足）：第 0 步（含分位≥80%）+ 前复权日收盘 ≤ 当月 forming 中轨 + 当周 forming %b ≤ 0.25 + 最低价 > 日中轨 + `0.5 < 日 %b ≤ 0.8`。
3. **滚动接单**：出现合法买点时，环形找**当前空仓**账号；若无空仓 → **新建**账号下单。成交后指针移到下一号。
4. **同月限购全局共用**：该股在同一自然月内最多买 1 次，不论哪个账号买过；被拦下的信号记「同月限购」。
5. **账号数 N**：按需模式下 = 回测中实际创建过的账号数（≈峰值并发持仓所需最小账户数）。也可手工固定 N（全忙则记 `miss_busy`、不新建）。
6. **资金池收益** = 全部账号期末权益之和 / (N × 100 万) − 1。单笔盈亏、本金浮亏仍按**单账号本金**看，不被池子稀释。
7. 重点看：各账号买卖时点、轮次盈亏、**本金最大浮亏**（见下）、价 MAE、是否回本及天数。

### 本金浮亏怎么算（回测重点指标）

对每一笔开仓轮次：

1. **成本** = 买入成交金额（不复权价 × 股数）。
2. 每日权益路径 = 已实现（卖出回笼 + 已收现金股息）+ 余仓 × 当日不复权收盘价。
3. **本金最大浮亏** = 路径上 `(权益 − 成本)` 的最小值（金额与相对成本的百分比）。
4. **回本**：曾跌破成本后，权益再次 ≥ 成本的首日；分别记「买入→回本」「谷底→回本」日历天数。
5. 价 MAE 只看买入价到最低价的跌幅，**不含**股息；本金浮亏含股息与已减仓回笼，更接近「这 100 万有没有亏进去」。

### 与实盘的差异（已知简化）

1. 按日收盘价成交，无滑点、无佣金印花税；买入用当日收盘，不模拟盘中限价。
2. 「站上中轨」用当日最低价与中轨比较，但成交仍落在收盘价。
3. 周/月线按「截至当日」forming K 对齐到日线（与实盘一致）；回测按日收盘推进，不模拟盘中分时。
4. 未建模停牌、涨跌停无法成交、融资融券等。
